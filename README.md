# K-080 LINE無料引換メモ v0.1

君たち株式会社／2026-10-08初期試作。**個人用の軽量一覧サイト**。追加費用を出さず、GitHub Pagesの無料公開枠を使う。

## 最初の公開（GitHubのWeb画面でOK）

1. GitHubで新しい**Public** repository（例：`line-coupon-memo`）を作る。
2. `index.html`、`style.css`、`main.js`、`campaigns.js`、`.nojekyll` をリポジトリの直下にアップロードする。`README.md`は任意。
3. Settings → Pages → Build and deployment → Source：**Deploy from a branch** → Branch：`main` → Folder：`/(root)` → Save。
4. GitHubのPages画面に出る公開URLで動作を確認。

*公開前に確認*：GitHub Freeの場合、Pages用リポジトリはPublic（公開）が必要。機密や個人情報はリポジトリに入れない。HTMLには広告タグや解析タグを含めない。

## 編集・更新

- **`campaigns.js`だけ編集すれば掲載案件を変更できる**。
- 新規追加は配列にデータを1件追加。既存の構造と項目を保つ。
- 公式の応募要項に照らして、LINE応募、購入不要、1万人以上、無料引換券を確認したもののみ追加。X応募や購入が必要な企画は除外。
- 応募締切が過ぎた案件は閲覧時に**自動非表示**。終了判定は日本時間の日時付き。
- `verifiedAt` は**実際に公式を確認した日**だけ入れる。未来の日を置かない。
- 締切は日本時間オフセット付きISO 8601（例 `2026-10-13T23:59:00+09:00`）。
- PCでも表示できますが、各社の応募自体はスマホ限定の場合があります。

## 動作と制限

- `index.html` を直接開いても表示可能。ネット接続は公式ページを開くときだけ必要。
- 「今日の応募済み」はブラウザーの `localStorage` に保存。次の日になるとチェックはリセット。別端末と同期はしない。
- **新しい懸賞の自動発見・収集・登録はまだ実装していない**。現段階で自動なのは期限切れ非表示だけ。
- 初回は一度サイトの使い勝手を見て、次に自動収集（取得先の利用条件・差分検知・AI審査・GitHub更新）を設計する。
- キャンペーンの参加条件や終了時刻は主催者による変更があり得るため応募先の公式ページを最終確認する。
